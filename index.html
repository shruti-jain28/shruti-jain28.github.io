    Patents

    US Patent #US12184742B1

    Automatic service discovery

    This system acts like an automated map-maker for complex software environments. By constantly monitoring how different computer programs communicate, it uses machine learning to analyze their behavior and categorize their relationships. Instead of a human having to manually document every connection, the technology automatically identifies when a specific group of processes is working together to perform a larger task.

    2023Granted
    US Patent #US20240422058A1

    Determining metrics including resource expenditures of a digital service

    This system calculates the total cost and resource usage of a specific digital service. It starts by finding all the individual components in a network and pinpointing which ones are actually used to run that service. By collecting the expenses for each of those parts and adding them together, it provides a clear, aggregated metric of the service's overall footprint, and displays it on the Service Map.

    2023Granted
    US Patent #US20250231851A1

    Issue detection and solution response

    This system monitors IT components to detect specific problems based on pre-set triggers. By collecting usage data from user devices, it identifies exactly when and where a fault occurs. This data is then fed into a generative AI model, which analyzes the context to automatically produce a tailored solution for the issue.
